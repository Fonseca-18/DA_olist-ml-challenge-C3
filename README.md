# 🛒 Olist ML Challenge — S12

**Reto de Machine Learning | Semana 12**

Repositorio académico dedicado al desarrollo del reto de *Machine Learning* utilizando datos del ecosistema de comercio electrónico de Olist. El proyecto organiza los datos, los notebooks de análisis y los reportes generados durante el proceso.

---

## 🎯 Objetivos del proyecto

- Explorar y preparar los datos para el análisis.
- Desarrollar las actividades prácticas propuestas en el reto.
- Aplicar técnicas de Machine Learning según los requerimientos de la guía.
- Interpretar los resultados obtenidos y documentar las conclusiones.

## 🚀 Cómo ejecutar el proyecto

1. Clonar el repositorio:

   ```bash
   git clone https://github.com/TU-USUARIO/olist-ml-challenge-s12.git
   ```

2. Abrir `notebooks/S12_ML_Challenge.ipynb` en Jupyter Notebook o Google Colab.
3. Configurar el identificador del estudiante como **13**, de acuerdo con las instrucciones de la actividad.
4. Ejecutar las celdas y completar las actividades e interpretaciones solicitadas.
5. Guardar el notebook ejecutado y el reporte JSON en la carpeta `reports/`.
